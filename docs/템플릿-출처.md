## 방식
- 임시 위치에 `git clone`으로 받은 뒤, `.git` 폴더를 제외한 모든 파일(숨김 폴더·설정 파일 포함)을 `my-business-site` 최상위로 복사함. 중첩 폴더(`my-business-site/ai-website-cloner-template/...`) 없이 바로 최상위에 위치.
- **원본 저장소에 연결되지 않음**: `.git` 폴더(커밋 이력·origin 원격 저장소 정보)는 복사하지 않았고, `my-business-site`는 별도의 git remote가 없는 독립 프로젝트 상태. 필요 시 직접 `git init` 후 원하는 원격 저장소를 새로 연결하면 됨.
- 기존 파일 보존: `docs/사업소개.md`, `docs/홈페이지-인터뷰.md`는 그대로 유지됨. 템플릿의 `docs/` 폴더(assets, design-references, research)는 파일명 충돌이 없어 같은 `docs/` 폴더 안에 추가로 병합됨.
- 충돌 여부 점검: 복사 전 템플릿의 전체 파일 73개 경로를 기존 `my-business-site` 파일과 대조해 충돌 0건 확인 후 진행함.
- `LICENSE` 파일은 템플릿 원본 그대로 유지함.
